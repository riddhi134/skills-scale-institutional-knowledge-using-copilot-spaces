# OctoAcme Project Management Docs

This folder contains OctoAcme's project management process documents. The goal of these docs is to make project management practices discoverable, consistent, and easy to onboard to for new team members.

## Summary

OctoAcme follows a lightweight, repeatable project management workflow that covers:

- Initiation — defining scope, goals, stakeholders, and success criteria.
- Planning — breaking work into milestones, estimating effort, and creating a delivery plan.
- Execution & tracking — running work using iterative sprints or milestones, tracking progress with issues and status updates, and managing dependencies.
- Release & deployment — coordinating release readiness, deployment steps, and post-release validation.
- Retrospectives & continuous improvement — running regular retrospectives and capturing action items to improve process and delivery.
- Risk management & communication — identifying, logging, and communicating risks and mitigation plans to stakeholders.
- Roles & personas — clarifying who is responsible for decisions, reviews, and coordination (e.g., PM, engineering lead, release manager, stakeholders).
